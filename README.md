# Chess
I made chess using OOP with a premade GUI, in computer science class.

### The menu
- When starting the program you will be presented with a menu
- In the options, you can choose between manual and automatic promotion (to queen)
- You can also choose if you want a timer, in which case you can choose the starting time and increment

### When playing
- Use the mouse to move
- Use escape to end the program
- Close the window to go back to the menu
- Use the buttons Q, R, B, and N to choose your promotion if auto promotion was turned of in the menu
- Use the left and right arrow keys to look at previous moves played
