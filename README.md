# Chess
I made chess using OOP with a premade GUI, in computer science class.


When starting the program you will be presented with a menu.


In the options, you can choose between manual and automatic (queen) promotion.

You can also choose if you want a timer, in which case you can choose the starting time and increment.

When playing a game, exiting the window brings you back to the menu.

To quit from the window press escape.
